# OpenWeb Benchmark — News

Created by **Dalto**. OpenWeb Benchmark measures how well configured search APIs
answer news questions using the evidence returned in their search responses.
The runner prepares question contracts, collects results, obtains independent
model judgments and writes HTML, JSON and CSV reports.

- [Start here](START.md) for a credential-free example.
- [Installation and first full run](INSTALL.md) for the question-to-report
  workflow, credentials and resume.
- [Providers](PROVIDERS.md) for configuration choices and how to change the roster.
- [Reproduce saved scores](REPRODUCE.md) for the separate benchmark data release.
- [Method and scope](openweb_news/assets/purpose-and-scope.md) for the grading,
  evidence and interpretation rules.
